The 1.0.0-rc1 release of Context Control Center (CCC) is the first release candidate after beta5. It focuses on making the admin UI and context selection reliable enough for production trials. Context item and consumer listings are easier to search and scan: each search word is matched separately, listings gained type and automatic-push filters plus summary pills, items now have a View link, and users with "Administer AI Context" can open the items list. Consumer types can inherit the site selection mode by default, Automator consumer wording and admin links are clearer, and the Rotterdam demo recipe includes answers-agent consumer configuration. Situational scopes now resolve correctly on API-proxy consumers such as AI CKEditor, and Tag and Taxonomy scope values are stored as entity UUIDs.

This release is built around a full pre-rc1 QA pass covering items, scopes, settings, agents, automators, CKEditor, Drupal 10, and upgrades. Fixes include white screens when editing AI agents or duplicating a published global item at the global limit, a status-report error after upgrading from beta4, General settings save failures on sites that started on 0.1.0-alpha1, missing SCMI scheduler fields, markdown document loading, automator widget clicks on later field deltas, and dropped conditional subcontext children on AI core 1.5.x. The unused "Create new revisions by default" setting was removed because revisions always happen. Subscribed-scope prefiltering no longer scans every published item ID, and the items listing keeps parent and child rows together across pages.
