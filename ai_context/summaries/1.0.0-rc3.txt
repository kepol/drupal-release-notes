The 1.0.0-rc3 release of Context Control Center (CCC) is the third release candidate for 1.0.0, and the last one that is planned before 1.0.0. Most changes come from the rc2 smoke test and from the 1.0.0 bug review. Translators can no longer change the settings that all languages share, such as the scopes, from the translation form. A detached "Same as parent" subcontext item is now unpublished in every translation. Automator requests get one context block each. On AI agents, the selection task is now the user request, not the agent instructions. Site Section patterns now match pages that have a language URL prefix. Get Relevant, the consumer form and post-update 0008 no longer fail on an include-list value with a non-ASCII character, and Never include also removes an item that the tool input gives with leading zeros. CCC now uses Scheduler's own permissions for context items and rejects schedules that the workflow cannot run.

This release also adds one new feature: an optional Token name for a context item, so that its text can be used as a Drupal token, for example [ai_context:item:brand_voice] in an AI agent system prompt. CCC now requires drupal/ai 1.4.12 or later on the 1.4 branch, or 1.5.2 or later. Read the upgrade notes before you update: you must run drush updatedb and then drush cr, and some changes need a check of your site.
